# party-death-markers

Spawns large beacons on top of dead party members. Fork of ![teralove/party-death-markers](https://github.com/teralove/party-death-markers) version.

## Commands

- `death show`: toggle mod on/off, default is on.
- `death dynamic`: toggle dynamic tank determination, default is on.

## Info

- Dynamic tank determination(disabled in raid) is based on history(last 5 minutes) of agro times. History clears on changes in party composition or on zone change.
- Tanks = red. DPS = violet. Healers = big blue-red swirl.
- The item cannot be picked up. It's fake. Spawned client-side for your eyes only. No body else can see them.
